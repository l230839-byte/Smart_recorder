1. OBJECTIVE
--------------------------------------------------------------------------------
The owner asked whether Qwen3 4B is the best offline model among Qwen, Kimi, DeepSeek,
GLM and GPT, and noted Ollama is installed. Find the best model that really runs on
the development computer (16 GB memory, Intel i5-1135G7, 4 cores, no graphics card),
prove it with the same live test, and offer it if it is better.


2. RESULT
--------------------------------------------------------------------------------
Qwen3 4B stays the recommended model. The newer Qwen3.5 small models were not better at
EchoMind's work on this computer. Qwen3.5 4B is added as an optional choice, with an
honest description; Qwen3.5 9B is not offered (the owner asked to cancel it, and the
test agreed).

Same test for every model: the two-voice meeting, Offline only ON, offline Whisper
Small, then summary, chapters, three chat questions and a 5-question quiz.

3. KEY DECISIONS
--------------------------------------------------------------------------------
D1  Kimi K2 (about 1 trillion parameters), DeepSeek V3/R1 (671B), GLM-4.5/4.6 (355B)
    and gpt-oss-120b need tens to hundreds of GB of memory: ruled out. gpt-oss-20b
    (12 GB) only just loads in 16 GB and leaves nothing for the rest of the computer.
    DeepSeek's small "R1 distill" models are retrained Qwen/Llama models that reason
    at length first, which is very slow on this processor.
D2  Qwen3.5 (March 2026, Apache-2.0) is rated the strongest family under 10B, so its
    4B and 9B were tested. Unsloth's 4-bit files are used, as for Qwen3; Qwen publishes
    no 4-bit files of its own. Hashes are the published SHA-256, checked after download.
D3  Qwen3.5 thinks before answering by default. EchoMind already turns thinking off for
    every offline model (--reasoning off and enable_thinking: false), which Qwen
    documents as the way to get direct answers. Our llama.cpp build (b12193) runs the
    new "qwen35" format with no change.
D4  Qwen3.5 4B: left out Ahmed's payment screen, gave Lena's test plan the payment
    screen's "Monday" deadline, and guessed a speaker's role. Kept as an option, after
    Qwen3 4B, because it is a valid newer model some may prefer; its description in
    Settings says what testing found.
D5  Qwen3.5 9B: as many facts as Qwen3 4B, but no clickable citations in its summary,
    1.7 times slower and about 7 GB of memory (only 5.2 GB was free during the test).
    Not offered; its downloaded test file was deleted at the owner's request.
D6  Ollama: a wrapper around the same llama.cpp engine EchoMind already includes. It
    would not make a model smarter or faster, so no Ollama connection was added.
D7  Because the default does not change, nobody's setup moves. A safeguard written for
    a changed default was removed again before commit.
