2. FIXES
--------------------------------------------------------------------------------
X1  Defaults updated to the models Groq offers today: openai/gpt-oss-120b first.
X2  Self-recovery: a retired model is now its own error. EchoMind asks the service which
    models it has, switches to the best one, saves it in Settings and carries on. Proven
    live: the test starts on the retired Llama model and finishes on gpt-oss-120b with
    no failed task. Results record the model that actually answered.
X3  Citations in other styles. gpt-oss wrote 【S1】 in one run and [ S1 ] in another, so
    the time links were lost. Both, and (S1) and ［S1］, are now linked and checked.
X4  Due dates. The model turned "by Friday", said on Thursday 19 November, into Wednesday
    25 November, and "next Monday" into a Saturday. Models now report only the words;
    EchoMind works out the date: weekdays, today and tomorrow, end of the week or month,
    "in 2 weeks", and written dates. Vague words ("next week") keep the words and get no
    invented date.
T1  A transcription test that failed now and then under load waited a fixed 30 ms; it now
    waits until the jobs stop changing. 0 failures in 6 full runs.

5. GEMINI (same meeting, same day)
--------------------------------------------------------------------------------
First run: every text task failed with "rejected". Two causes:
- The live test switches provider from Groq to Gemini, and the Groq model name stayed
  in the shared text-model setting, so Gemini was asked for a model it does not have.
  A person changing provider in Settings would hit the same thing.
- Gemini answers an unknown model with a bare 404 and no message, so the self-recovery
  from section 2 (X2) never started: it only knew Groq's "model not found" wording.

Fixes:
G1  Changing the provider clears a model name that is not one of the new provider's,
    so its default is used. A model chosen in the same change is kept.
G2  A 404 on a chat request now counts as a missing model and starts the self-recovery.
    If the model list cannot be read either, the original error is shown, since the
    address is then the likely problem.
G3  Gemini lists its models as "models/gemini-..."; the prefix is removed so a switched
    model can be used directly.
G4  Gemini titled one action item "Test it". Task titles must now name the thing
    ("Test the payment screen").
Unit tests cover G1 to G3 with Gemini's real reply shapes.

Final run on gemini-3.5-flash-lite (about 3 seconds per task, 10 requests, 8,600 tokens):
- Structured summary: 29 citations kept, 0 invented. The checker found 11 of 12; the
  twelfth is there in another word order ("Friday: Ahmed to finish the payment screen").
